# Development Workflow

**Update**

```
Resume: | Rationalize | Resolve | Refine | Review |

1. Update the status of the task document @/.task.md , @/docs/amazon-seller-tools/documentation.md and @/src/app/content/blog/amazon-seller-tools.mdx based on @git-changes. Proceed to step 2 if no significant changes.
2. Address these problems @problems @/typecheck-output.txt if no errors and warnings available, proceed to step 3.
3. Continue the pending implementation outlined on @/.task.md
4. Find potential bugs and opportunities for improvements using static analysis tools (e.g., ESLint, SonarQube) and code review checklists.
5. @git-changes Use git command to push changes and create meaningful commit messages.
```

**Code Checking**

```
Execute the `npm run check` command. If the check fails (exits with a non-zero code), analyze the output to identify and resolve the issues.
```

**Build**

```
Execute the `npm run build` command. If the build fails (exits with a non-zero code), analyze the output to identify and resolve the issues.
```

**Run**

```
1. Execute: npm run dev
2. Analyze the web page at `http://localhost:3000/` for usability, accessibility (using tools like WAVE or Axe), performance (using browser developer tools), and design. Provide specific, actionable recommendations for improvement, including code snippets or examples where applicable. Prioritize suggestions based on impact and feasibility, and categorize them by area (e.g., UI/UX, SEO, Code Optimization).
```

**Rationalize**

```
Develop and execute a comprehensive action plan to integrate suggested improvements, ensuring minimal disruption to existing functionality and adherence to best practices.
```

**Resolve**

```
Implement the changes outlined in the action plan, focusing on code quality, maintainability, and scalability.
```

**Refine**

```
Analyze the Amazon Seller Central dashboard and related tools to identify actionable, incremental improvement opportunities specifically designed to enhance usability, streamline workflows, or provide clearer insights, focusing on changes that can be implemented in small, committable steps.

Reference:
@/.task.md
@/docs/amazon-seller-tools/documentation.md
@git-changes
```
