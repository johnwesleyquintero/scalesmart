Develop a comprehensive data integration system enabling users to upload, map, transform, and merge multiple CSV reports into a unified dataset for dashboard visualization, mirroring a Looker Studio/Power BI-like experience with enhanced user-friendliness.

Core Functionality:

1.  Multi-File Upload & Management:

    - Allow users to upload multiple CSV files simultaneously.
    - Track each file's metadata (name, raw data preview, processing status: raw, mapped, error).
    - Provide a user interface for file management (upload, view, remove, map, merge).

2.  Individual Report Mapping:

    - Utilize `GenericCsvDataMapper.tsx` for individual column mapping to `TARGET_METRICS_CONFIG` (e.g., `DashboardMetrics`).
    - Enable data transformations (trim, case, find/replace) during mapping.
    - Implement a mechanism to associate a `toolName` (e.g., "SQP_Report_Upload") with each file for loading/saving specific mapping preferences.

3.  Data Modeling & Merging ("Smart Suggestion & Join Logic"):

    - After individual file mapping, facilitate the definition of relationships between datasets.
    - Implement "Smart Suggestions" for join keys:
      - Suggest join keys based on columns mapped to the same `targetMetric.key`.
      - Analyze column names for string similarity.
      - Compare data types and value distributions.
      - Incorporate semantic analysis and machine learning techniques for more accurate suggestions.
    - Provide options for users to create composite keys or generate unique keys if necessary.
    - Allow users to configure join types (inner, left, etc.).

4.  Data Transformation & Cleaning (Post-Mapping, Pre-Merge):

    - Apply generalized transformation logic (from `src/lib/utils/data-transformation.ts`) to each row of each mapped file, utilizing `src/workers/data-transformation.worker.ts` for efficient background processing.
    - Expand transformation capabilities to include data type conversion, data aggregation, and custom functions.

5.  Data Validation:

    - Implement data validation rules to ensure data quality, including data type validation, range validation, and regular expression validation.

6.  Error Handling:

    - Provide detailed error messages and guidance on how to resolve errors throughout the application.

7.  Support for More Data Sources:

    - Add support for importing data from the Amazon Seller Central API, databases (MySQL, PostgreSQL, MongoDB), and spreadsheets (Excel, Google Sheets).

8.  Persistent Storage (IndexedDB):

    - Store raw file information/previews.
    - Persist individual mappings (extending `userCsvMappings` in `GenericCsvDataMapper.tsx`).
    - Store individually mapped and transformed datasets (arrays of `DashboardMetrics`).
    - Store merge configurations (join keys, join types).
    - Store merged datasets.

9.  User-Controlled Dashboard Visualization:

    - Enable users to select a dataset for dashboard display:
      - Individual processed report.
      - Previously configured merged dataset.
    - Ensure existing dashboard components (e.g., `OverviewDataView`, `OverviewDataTable`) render based on the selected dataset.
