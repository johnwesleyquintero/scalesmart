### Overview Dashboard

**Status**: ✅ Active
**Version**: 1.1.0

🔍 **Description**: Centralized dashboard for business report analysis, KPI tracking, and trend visualization. Charts are now rendered using the ReusableChart component. Includes CSV Data Mapper with data validation and Sample CSV download.
The Overview Dashboard is a central hub for analyzing key business metrics. It allows users to upload their Amazon Business Report data (in CSV format), visualize key performance indicators (KPIs), analyze trends, and access a variety of specialized tools. The CSV Data Mapper now includes data validation to ensure data integrity. Charts are now rendered using the ReusableChart component for improved consistency and maintainability.

**How to Use the Overview Dashboard:**

1.  **Uploading Data:**
    1.  Click "Choose Report File (.csv)".
    2.  Select your CSV file.
    3.  **Column Mapping:** Use the `GenericCsvDataMapper` component to map CSV columns to the required data fields.
        - Select the corresponding column from your CSV using the dropdown menus.
        - Hints are provided for each target field to guide you.
        - A sample data row from your CSV is shown to help with mapping.
        - Required fields must be mapped.
        - Click "Apply Mapping" to process the file and save the mapping preferences, or "Cancel" to abort. You can also click "Reset" to reset the mapping to the default values.
        - Added a transformation configuration modal to allow users to configure transformations for each mapped field.
2.  **Viewing Data:**
    - **KPI Cards:** Display overall averages or totals for metrics like "Avg. Conversion Rate," "Total Sales," and "Avg. Clicks."
    - **Period-over-Period Comparison KPIs:** Shows key metrics (Total Sales, Total Orders, Conversion Rate, ACoS, RoAS) for the most recent period compared to the previous one. Changes are indicated with icons (up/down arrows) and percentage differences.
    - **Charts:** Visualizing trends for sales, advertising performance (clicks, impressions), and engagement (orders, sessions) using the ReusableChart component.
    - **Data Table:** Displaying the data in a sortable and filterable table using the `MetricsDataTable` component.
3.  **Time Granularity:** Use the "Select Time Granularity" dropdown to change the aggregation period (Daily, Weekly, Monthly, Quarterly, Yearly). Charts and KPI comparisons will update accordingly.
4.  **Time Range Filtering:** Use the time range selector in the top right corner of each chart to filter the data by time range (Last 7 Days, Last 30 Days, Last 90 Days, Year to Date, All Time).
5.  **Period-over-Period Comparison:** The dashboard displays period-over-period comparisons for key metrics (Total Sales, Total Orders, Conversion Rate, ACoS, RoAS). Changes are indicated with icons (up/down arrows) and percentage differences.
6.  **Interacting with the Dashboard:**
    - The dashboard now displays sample data when no CSV file is uploaded.
    - **Refresh:** Click the "Refresh" button in the header to clear current data and start over.
    - **Export:** Click the "Export" button to download the currently processed and aggregated dashboard metrics as a CSV file.
    - **Docs:** Links to external documentation for the Amazon Seller Tools.
    - **Error Handling:** If issues occur during file upload, parsing, or mapping, an error message will be displayed. You'll often have an option to "Try uploading again."

## ACoS Calculator

The ACoS Calculator (`src/app/amazon-seller-tools/acos-calculator.tsx`) is a tool for calculating the Advertising Cost of Sales. It allows users to input campaign data either via CSV upload or manual entry, and then calculates and displays the ACoS and RoAS. The calculator also saves the calculation history to IndexedDB and displays it in a table, and visualizes ACoS trends over time using a chart.

### Input Methods

The ACoS Calculator provides two methods for inputting campaign data:

-------
- **CSV Upload:** Users can upload a CSV file containing campaign data. The CSV file should have columns for `Campaign`, `AdSpend`, and `Sales`. Optional columns include `Impressions` and `Clicks`.
- **Manual Entry:** Users can manually enter data for a single campaign using the `ManualCalculationForm` component.

### Manual Calculation Form

The `ManualCalculationForm` component (`src/components/amazon-seller-tools/ManualCalculationForm.tsx`) allows users to manually enter data for a single campaign. The form includes the following fields:

- **Campaign Name:** The name of the campaign.
- **Ad Spend ($):** The amount spent on advertising.
- **Sales ($):** The revenue generated from advertising.
- **Impressions:** The number of impressions.
- **Clicks:** The number of clicks.

### ACoS Rating Guide

The `AcosRatingGuide` component (`src/components/amazon-seller-tools/AcosRatingGuide.tsx`) displays a guide for interpreting ACoS values. The guide includes the following ratings:

- **Excellent:** ACoS is less than 15%.
- **Good:** ACoS is between 15% and 25%.
- **Okay:** ACoS is between 25% and 35%.
- **Poor:** ACoS is greater than 35%.

### Calculation History Table

The `CalculationHistoryTable` component (`src/components/amazon-seller-tools/CalculationHistoryTable.tsx`) displays a table of the calculation history, including the following columns:

- Campaign
- Date
- Ad Spend
- Sales
- ACoS
- RoAS

### ACoS Trend Chart

The `AcosTrendChart` component (`src/components/amazon-seller-tools/AcosTrendChart.tsx`) visualizes the ACoS over time using a line chart. The chart displays the ACoS values for each saved calculation, allowing users to track ACoS trends.

## Frequently Asked Questions

**Q: How does the Overview Dashboard handle data from CSV files with varying column lengths?**

A: The Overview Dashboard is designed to handle CSV files where columns might not have the same number of rows. The data transformation process extracts data from each row independently, and missing values are treated as either `undefined` or 0. The data aggregation logic then aggregates the available data for each time period, ensuring that calculations are accurate even with missing data.

**Q: What types of data sources are supported by the Overview Dashboard?**

A: The Overview Dashboard primarily supports data from Amazon Business Reports in CSV format.

**Q: How accurate are the calculations in the Overview Dashboard?**

A: The calculations in the Overview Dashboard are based on the data provided in the uploaded CSV file. We strive to ensure accuracy by using well-tested algorithms and providing clear documentation.

**Q: Can I trust the data displayed in the Overview Dashboard?**

A: Yes, you can trust the data displayed in the Overview Dashboard. We have implemented robust error handling and validation mechanisms to ensure data integrity. However, it's important to ensure that the uploaded CSV file is accurate and properly mapped to the corresponding data fields.

**Q: What if some data is missing in my CSV file?**

A: The Overview Dashboard is designed to handle missing data gracefully. Missing values will be treated as either `undefined` or 0, and the calculations will be adjusted accordingly.
