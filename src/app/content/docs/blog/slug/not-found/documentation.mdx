# Blog Post Not Found Page Documentation (`src/app/blog/[slug]/not-found.tsx`)

## Overview

The `src/app/blog/[slug]/not-found.tsx` file defines a custom not-found page for individual blog posts. It is displayed when a blog post with the specified slug does not exist.

## Functionality

- **Displays Not Found Message:** Displays a message indicating that the requested blog post could not be found.
- **Provides Back to Blog Link:** Provides a link to navigate back to the main blog page.

## Technical Details

- The page uses the `ui/button` component from the `@/components/ui` library.
- The page uses the `lucide-react` library for icons.
- The page uses the `next/link` component for navigation.

## Data Flow

1.  The `BlogNotFound` component is rendered when a blog post with the specified slug does not exist.
2.  The component displays the not-found message and a link to navigate back to the main blog page.
