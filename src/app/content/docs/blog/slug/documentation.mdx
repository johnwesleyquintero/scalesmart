# Blog Post Page Documentation (`src/app/blog/[slug]/page.tsx`)

## Overview

The `src/app/blog/[slug]/page.tsx` file defines the individual blog post page. It fetches the blog post data based on the slug and renders the content using `next-mdx-remote/rsc`. It also generates metadata for the page and handles the case where the post is not found.

## Functionality

- **Fetches Blog Post by Slug:** Fetches the blog post data based on the slug using the `getPostBySlug` function from `@/lib/mdx`.
- **Renders MDX Content:** Renders the blog post content using `next-mdx-remote/rsc`.
- **Generates Metadata:** Generates metadata for the page, including the title, description, and Open Graph properties.
- **Handles Not Found Case:** Handles the case where the blog post is not found using the `notFound` function from `next/navigation`.

## Technical Details

- The page uses the `getPostBySlug` function from `@/lib/mdx` to fetch the blog post data.
- The page uses the `MDXRemote` component from `next-mdx-remote/rsc` to render the MDX content.
- The page uses the `Metadata` type from `next` to generate metadata for the page.
- The page uses the `notFound` function from `next/navigation` to handle the case where the blog post is not found.

## Data Flow

1.  The `BlogPostPage` component is rendered with the `slug` parameter.
2.  The component calls the `getPostBySlug` function to fetch the blog post data based on the slug.
3.  If the blog post is not found, the `notFound` function is called, which renders the `not-found.tsx` page.
4.  If the blog post is found, the component renders the blog post content using the `MDXRemote` component.
5.  The `generateMetadata` function is called to generate metadata for the page.
