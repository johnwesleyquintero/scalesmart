# Amazon Seller Tools Page Documentation

## Overview

The Amazon Seller Tools page (`src/app/amazon-seller-tools/page.tsx`) is a comprehensive dashboard designed for Amazon sellers. It allows users to upload Amazon Business Report data in CSV format, visualize key performance indicators (KPIs), analyze trends, and access specialized tools for keyword research, listing optimization, financial calculations, PPC analysis, and competitor research.

## Key Features

- **CSV Data Upload and Mapping:** Upload and map CSV files to predefined DashboardMetrics fields.
- **Dashboard Visualization:** KPI cards and data tables for visualizing metrics.
- **Time Granularity Control:** Aggregate data daily, weekly, monthly, quarterly, or yearly.
- **Time Range Filtering:** Filter data by specific time ranges.
- **Period-over-Period Comparison:** Compare key metrics across different periods.
- **Specialized Tool Suite:** Tools organized into tabs for Keywords, Listing Optimization, Financials, PPC & Ads, and Competition.
- **Data Export:** Export processed data as CSV.
- **Print and Download PDF:** Share dashboard insights easily.
- **Sample Data:** Load sample data to explore functionality without uploading personal data.
- **Keyword Performance Overview Table:** Toggleable table for granular keyword performance insights.

## How to Use the Overview Dashboard

1. **Navigate to the Page:** Access via main navigation.
2. **Upload CSV Data:** Click "Upload CSV" and select your file.
3. **Map CSV Columns:** Use the OverviewDataMapper to map CSV columns to DashboardMetrics fields.
4. **View Dashboard:** Interact with charts, tables, and filters to analyze data.
5. **Interact with Data:** Sort, filter, export, and refresh data as needed.

## Data Models & Interfaces

### DashboardMetrics Interface

The dashboard processes uploaded data into a standardized `DashboardMetrics` object for each data row/period. Key fields include:

- `date`
- `sales`
- `orders`
- `conversionRate`
- `acos`
- `roas`

### CampaignData Interface

The dashboard processes uploaded data and manual input into a standardized `CampaignData` object. Key fields include:

- `campaignName`
- `adSpend`
- `sales`
- `impressions`
- `clicks`

## Specialized Tool Tabs

- **Keywords:** Tools for keyword research and analysis.
- **Listing Optimization:** Tools to improve product listings.
- **Financials:** Calculators for financial metrics.
- **PPC & Ads:** Tools for managing and auditing PPC campaigns.
- **Competition:** Tools for analyzing competitors.

## ACoS Calculator Details

The ACoS Calculator (`src/components/amazon-seller-tools/acos-calculator.tsx`) calculates the Advertising Cost of Sales. It allows manual data input and displays ACoS and RoAS.

### Input Methods

- **Manual Entry:** Enter data for a single campaign using the `ManualCalculationForm` component.

### Manual Calculation Form

The `ManualCalculationForm` component includes fields for:

- `Campaign Name`
- `Ad Spend ($)`
- `Sales ($)`
- `Impressions`
- `Clicks`
- `Clear History`

### ACoS Rating Guide

The `AcosRatingGuide` component displays ratings for interpreting ACoS values:

- **Excellent:** ACoS < 15%
- **Good:** 15% ≤ ACoS ≤ 25%
- **Okay:** 25% < ACoS ≤ 35%
- **Poor:** ACoS > 35%

### Calculation History Table

The `CalculationHistoryTable` component displays:

- `Campaign`
- `Date`
- `Ad Spend`
- `Sales`
- `ACoS`
- `RoAS`

### ACoS Trend Chart

The `AcosTrendChart` component visualizes ACoS over time using a line chart.

## Technical Overview

- **Frontend:** TypeScript and React (Next.js).
- **UI Components:** ShadcnUI components.
- **Charting:** Recharts library.
- **CSV Parsing:** PapaParse library.
- **Date Manipulation:** date-fns library.
- **State Management:** React hooks.
- **IndexedDB:** Local data storage.
- **Supabase:** Cloud storage for configurations.
- **Logging:** Added to `handleDownloadSampleCsv` function.
