# ScaleSmart Troubleshooting Guide

This guide provides solutions to common issues you might encounter while setting up or using the ScaleSmart Platform and its Command Line Interface (CLI). If you don't find a solution here, please refer to our [support documentation](https://www.scalesmart.com/support) or contact our support team.

## 1. CLI Installation Issues

### Issue: `scalesmart` command not found

**Description:** After installing the CLI, running `scalesmart --version` or any other `scalesmart` command results in an error like `'scalesmart' is not recognized as an internal or external command` (Windows) or `command not found` (Linux/macOS).

**Possible Causes:**

- npm global packages directory is not in your system's PATH environment variable.
- Installation failed due to permissions.

**Solutions:**

- **Verify PATH:**
  - **Windows:** Search for "Environment Variables" in the Start menu, open "Edit the system environment variables," click "Environment Variables...", find "Path" under "System variables," and ensure `C:\Users\<YourUser>\AppData\Roaming\npm` (or similar) is listed.
  - **macOS/Linux:** Check your shell's configuration file (`.bashrc`, `.zshrc`, `.profile`) for a line similar to `export PATH="/usr/local/bin:$PATH"` and ensure npm's global bin directory is included. You might need to restart your terminal after making changes.
- **Reinstall with Permissions:**
  - **Linux/macOS:** Try `sudo npm install -g scalesmart-cli`.
  - **Windows:** Run your command prompt or PowerShell as an administrator, then `npm install -g scalesmart-cli`.

### Issue: npm permission errors during global installation

**Description:** You see `EACCES` errors (Linux/macOS) or similar permission denied messages when trying to install globally.

**Possible Causes:**

- Your user does not have write permissions to the global npm directory.

**Solutions:**

- **Use `sudo`:** (As above) `sudo npm install -g scalesmart-cli`.
- **Change npm's default directory:** This is a more permanent solution. Follow npm's official guide on [fixing npm permissions](https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally).

## 2. Configuration and Authentication Issues

### Issue: Invalid API Key or Authentication Failed

**Description:** Commands requiring authentication fail with "Invalid API Key," "Authentication Failed," or "Unauthorized" errors.

**Possible Causes:**

- Incorrect API key entered during configuration.
- API key has expired or been revoked.
- Network connectivity issues preventing communication with the authentication server.

**Solutions:**

- **Reconfigure API Key:**
  ```bash
  scalesmart config set api_key YOUR_NEW_API_KEY
  ```
  Ensure you copy the API key exactly from your ScaleSmart account dashboard.
- **Generate New API Key:** If your key might be compromised or expired, generate a new one from your ScaleSmart account dashboard and reconfigure.
- **Check Network:** Ensure you have a stable internet connection and no firewalls or proxies are blocking access to `api.scalesmart.com`.

### Issue: `scalesmart config set` command not saving settings

**Description:** After running `scalesmart config set`, the settings don't seem to persist or are not applied.

**Possible Causes:**

- Issues with file permissions for the configuration file.
- CLI version bug.

**Solutions:**

- **Check Configuration File:** The configuration file is usually located in your user's home directory (e.g., `~/.scalesmart/config.json` on Linux/macOS, `%USERPROFILE%\.scalesmart\config.json` on Windows). Verify its existence and permissions.
- **Update CLI:** Ensure you are running the latest version of the CLI (`npm update -g scalesmart-cli`).

## 3. Project Initialization Issues

### Issue: `scalesmart new` command fails or creates incomplete project

**Description:** When initializing a new project, the command fails or the created directory is missing files.

**Possible Causes:**

- Insufficient disk space.
- Permissions issues in the target directory.
- Network issues preventing template downloads.

**Solutions:**

- **Check Disk Space:** Ensure you have enough free disk space in the location where you are trying to initialize the project.
- **Directory Permissions:** Verify that your user has write permissions to the directory where you are running `scalesmart new`.
- **Network Connectivity:** Confirm stable internet access to download project templates.

## 4. General Operation Issues

### Issue: Commands are slow or time out

**Description:** CLI commands take a long time to execute or return timeout errors.

**Possible Causes:**

- Poor network connectivity.
- High load on ScaleSmart servers.
- Large data operations.

**Solutions:**

- **Check Internet Speed:** Test your internet connection speed.
- **Retry:** Sometimes, transient network issues can cause timeouts. Try running the command again.
- **Monitor Status Page:** Check the [ScaleSmart Status Page](https://status.scalesmart.com) for any ongoing service disruptions.

### Issue: Unexpected errors or crashes

**Description:** The CLI crashes or returns generic error messages without clear explanations.

**Possible Causes:**

- Bug in the CLI.
- Corrupted local installation.
- Incompatible Node.js version.

**Solutions:**

- **Consult Logs:** The CLI might generate detailed logs. Look for a `logs` directory within your `.scalesmart` configuration directory or check your terminal output for paths to log files.
- **Reinstall CLI:** Perform a clean reinstall:
  ```bash
  npm uninstall -g scalesmart-cli
  npm install -g scalesmart-cli
  ```
- **Update Node.js:** Ensure your Node.js version meets the [prerequisites](/docs/prerequisites).

## Still Having Trouble?

If you've gone through this guide and are still experiencing issues, please gather the following information before contacting support:

- Your operating system and version.
- Node.js and npm versions (`node -v`, `npm -v`).
- ScaleSmart CLI version (`scalesmart --version`).
- The exact command you ran.
- The full error message and any stack traces.
- Relevant log file contents.

You can reach our support team via [email](mailto:support@scalesmart.com) or through our [community forum](https://community.scalesmart.com).
