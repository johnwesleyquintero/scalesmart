# API Documentation Overview

This directory contains documentation for the various API endpoints used in the ScaleSmart application.

## Purpose

The API documentation provides details on how to interact with the application's backend services, including:

- Request and response formats
- Authentication requirements
- Available parameters
- Error handling

## Subdirectories

- **academy-article/:** API endpoints for managing academy articles.
- **academy-courses/:** API endpoints for managing academy courses.
- **amazon/:** API endpoints for Amazon integrations.
- **auth/:** API endpoints for authentication.
- **chat/:** API endpoints for chat functionality.
- **contact/:** API endpoints for contact forms.
- **content/:** API endpoints for content management.
- **download/:** API endpoints for file downloads.
- **module-progress/:** API endpoints for tracking module progress.
- **prohibited-keywords/:** API endpoints for managing prohibited keywords.
- **redis/:** API endpoints for Redis interactions.
- **resume/:** API endpoints for resume management.
- **search/:** API endpoints for search functionality.

## General Guidelines

- All API endpoints require proper authentication.
- Request and response formats are typically JSON.
- Error responses will include appropriate HTTP status codes and error messages.

Further details on each endpoint can be found in the respective subdirectory.
