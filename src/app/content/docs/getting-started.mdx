Welcome to the ScaleSmart Platform! This guide will help you quickly get started with local operations using the Command Line Interface (CLI). By following these steps, you'll be able to set up and run core platform functionalities on your local machine, providing a foundation for development and testing.

### Setting Up Locally via CLI

To begin working with ScaleSmart locally, you'll primarily interact with our dedicated CLI tool. Ensure you have met the [prerequisites](/docs/prerequisites) before proceeding. For a detailed setup, refer to the [CLI Installation Guide](/docs/cli-installation).

1.  **Install the ScaleSmart CLI:**
    Follow the installation instructions for your operating system outlined in the [CLI Installation Guide](/docs/cli-installation). This typically involves downloading the appropriate package or using a package manager.

    ```bash
    # Install the ScaleSmart CLI globally
    npm install -g scalesmart-cli
    ```

2.  **Configure Your Environment:**
    Once installed, you'll need to configure the CLI with your platform credentials or necessary API keys. This step secures your connection and authorizes local operations.

    ```bash
    # Configure the CLI with your API key
    scalesmart config set api_key YOUR_API_KEY
    ```

    You will be prompted to enter required information.

3.  **Initialize Your Project (Optional, but recommended):**
    For managing specific projects or configurations locally, you might want to initialize a local project directory.

    ```bash
    # Initialize a new project
    scalesmart new my-local-project
    ```

    This command sets up necessary configuration files in your current directory.

4.  **Run Your First Command:**
    Test your setup by running a basic command, such as checking the CLI version or fetching some initial data (if applicable to your setup).
    ```bash
    scalesmart --version
    scalesmart status # Example check command
    ```

### Common Troubleshooting

Encountering issues during setup is sometimes unavoidable. Here are a few initial tips:

- **Verify Installation:** Double-check that the CLI installed correctly and the `scalesmart` command is accessible in your terminal's PATH.
- **Check Configuration:** Ensure the credentials and endpoints configured are correct and have the necessary permissions.
- **Consult Logs:** The CLI or platform components might generate local logs that provide clues about errors.
- **Connectivity:** Verify network connectivity if your setup requires communication with remote services.

For more detailed solutions and a comprehensive list of common problems, please refer to the dedicated [Troubleshooting Guide](/docs/troubleshooting).

This guide provides a quick path to getting operational locally. Explore the further documentation linked throughout for deeper dives into specific features and advanced configurations.
