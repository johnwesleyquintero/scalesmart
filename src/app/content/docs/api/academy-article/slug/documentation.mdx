# Academy Article API Endpoint Documentation (`src/app/api/academy-article/[slug]/route.ts`)

## Overview

The Academy Article API endpoint (`src/app/api/academy-article/[slug]/route.ts`) retrieves academy articles from MDX files based on their slug. It reads the MDX file, parses the frontmatter, serializes the content, and returns the serialized MDX source and frontmatter as a JSON response.

## Functionality

- **Retrieves Academy Articles by Slug:** Retrieves academy articles from MDX files based on their slug.
- **Parses Frontmatter:** Parses the frontmatter from the MDX file.
- **Serializes MDX Content:** Serializes the MDX content using `next-mdx-remote/serialize`.
- **Returns JSON Response:** Returns the serialized MDX source and frontmatter as a JSON response.

## Technical Details

- The endpoint uses the `fs` module to read the MDX file.
- The endpoint uses the `matter` library to parse the frontmatter.
- The endpoint uses the `next-mdx-remote/serialize` library to serialize the MDX content.
- The endpoint uses the `NextResponse` object from `next/server` to return the JSON response.
- The endpoint defines the directory where the MDX blog/article content is stored.

## Data Flow

1.  A request is made to the `/api/academy-article/[slug]` endpoint, where `[slug]` is the slug of the academy article.
2.  The endpoint validates the slug to ensure it only contains allowed characters (alphanumeric, hyphens, and underscores).
3.  The endpoint reads the MDX file from the file system.
4.  The endpoint parses the frontmatter from the MDX file using the `matter` library.
5.  The endpoint serializes the MDX content using the `next-mdx-remote/serialize` library.
6.  The endpoint returns the serialized MDX source and frontmatter as a JSON response.
