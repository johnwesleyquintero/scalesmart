# Amazon Competitor Analysis API Endpoint Documentation (`src/app/api/amazon/competitor-analysis/route.ts`)

## Overview

The Amazon Competitor Analysis API endpoint (`src/app/api/amazon/competitor-analysis/route.ts`) performs competitor analysis based on uploaded CSV data. It processes the CSV data, extracts metrics, and currently returns static case study data.

## Functionality

- **Processes CSV Data:** Processes uploaded CSV data for seller and competitor information, converting it into a structured format.
- **Extracts Metrics (Internal):** Extracts specified metrics (e.g., price, reviews) from the processed CSV data internally for analysis.
- **Returns Static Response:** Currently returns static 'case-studies' data as a JSON response. Note that the internally extracted competitor metrics are not currently included in the API response.

## Technical Details

- The endpoint uses the `zod` library to validate the request body.
- It expects CSV data containing headers like `asin`, `price`, `reviews`, `rating`, `conversion_rate`, and `click_through_rate`.
- The `processCSVData` function (defined within [`src/app/api/amazon/competitor-analysis/route.ts`](src/app/api/amazon/competitor-analysis/route.ts)) is used to parse the CSV data, handling type conversions for numerical fields and defaulting invalid numbers to 0.
- The `loadStaticData` function is used to fetch static case study data, which is currently returned by the API.

## Request Body

The API accepts a `POST` request with a JSON body containing the following parameters:

| Parameter        | Type       | Description                                                                                                                                                                                                                                                    | Required | Example                                          |
| :--------------- | :--------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------- | :----------------------------------------------- |
| `sellerData`     | `string[]` | An array of strings, where each string is a line from the CSV file representing the seller's product data. The first line should be the header row.                                                                                                            | Yes      | `["asin,price,reviews", "B09ABCDEFG,25.99,150"]` |
| `competitorData` | `string[]` | An array of strings, where each string is a line from the CSV file representing competitor product data. The first line should be the header row.                                                                                                              | Yes      | `["asin,price,reviews", "B08HIJKLM,24.50,300"]`  |
| `metrics`        | `string[]` | (Optional, but recommended for internal processing) An array of strings specifying which metrics to extract from the CSV data (e.g., "price", "reviews", "rating"). If provided, metrics are processed internally, but not currently returned in the response. | No       | `["price", "reviews"]`                           |
| `asin`           | `string`   | (Optional) A single ASIN for direct product analysis. While accepted, the primary analysis currently relies on `sellerData` and `competitorData` CSV uploads.                                                                                                  | No       | `"B07ZYW34RT"`                                   |

### Example Request

```json
POST /api/amazon/competitor-analysis
Content-Type: application/json

{
  "sellerData": [
    "asin,price,reviews,rating,conversion_rate,click_through_rate",
    "B09ABCDEDF,25.99,150,4.2,0.05,0.02"
  ],
  "competitorData": [
    "asin,price,reviews,rating,conversion_rate,click_through_rate",
    "B08HIJKLM,24.50,300,4.5,0.06,0.03",
    "B07QRSTUV,26.00,100,4.0,0.04,0.01"
  ],
  "metrics": ["price", "reviews", "rating"]
}
```

## Response

Upon successful processing, the API currently returns a JSON object containing static 'case-studies' data.

### Success Response Example (200 OK)

```json
{
  "data": [
    {
      "title": "Case Study: Optimizing Listing Images for Higher Conversion",
      "slug": "optimizing-listing-images",
      "date": "2023-03-10",
      "content": "This case study examines how optimizing product images on Amazon led to a 15% increase in conversion rate for a new electronics product."
    },
    {
      "title": "Case Study: Leveraging Customer Reviews for Product Improvement",
      "slug": "leveraging-customer-reviews",
      "date": "2023-04-01",
      "content": "An analysis of how feedback from Amazon customer reviews can be effectively used to refine product features and increase customer satisfaction."
    }
  ]
}
```

### Error Response Example (400 Bad Request / 500 Internal Server Error)

```json
{
  "message": "Error description here",
  "errorCode": "ERROR_CODE",
  "details": "Additional error details or issues"
}
```

Common `errorCode` values:

- `VALIDATION_ERROR`: When the request body does not conform to the expected schema (e.g., missing required fields, invalid types).
- `MISSING_DATA`: When `sellerData` or `competitorData` is missing.
- `UNKNOWN_ERROR`: For any other unexpected server-side errors.

## Data Flow

1.  A POST request is made to the `/api/amazon/competitor-analysis` endpoint with seller and competitor CSV data in the request body.
2.  The endpoint validates the request body using the `zod` library.
3.  The `sellerData` and `competitorData` CSV strings are processed by the `processCSVData` function to parse the data into structured arrays of product objects.
4.  If specified in the request, metrics are internally extracted from the combined seller and competitor data for potential future use.
5.  The endpoint retrieves static 'case-studies' data using `loadStaticData('case-studies')`.
6.  The endpoint returns the static 'case-studies' data as a JSON response.
