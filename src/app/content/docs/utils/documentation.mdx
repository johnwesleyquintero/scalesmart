# Utility Functions Documentation (`src/lib/utils.ts`)

This document provides an overview and usage details for the utility functions defined in `src/lib/utils.ts`.

## `cn`

The `cn` function is a utility for conditionally joining CSS class names together. It leverages `clsx` and `tailwind-merge` to efficiently combine class strings, resolve conflicts, and ensure proper Tailwind CSS class ordering.

### Function Signature

```typescript
function cn(...inputs: ClassValue[]): string;
```

### Parameters

- `inputs`: An array of `ClassValue` (which can be strings, objects, or arrays of `ClassValue`).

### Return Value

A single string containing merged and optimized CSS class names.

### Example

```typescript
import { cn } from '@/lib/utils';

const isActive = true;
const buttonClasses = cn(
  'p-2',
  'bg-blue-500',
  isActive && 'text-white',
  { 'font-bold': isActive },
  'hover:bg-blue-700',
);
console.log(buttonClasses); // Output: "p-2 bg-blue-500 text-white font-bold hover:bg-blue-700"
```

## `generateSlug`

The `generateSlug` function generates a URL-friendly slug from a given title string. It converts the title to lowercase, replaces spaces with hyphens, removes non-alphanumeric characters (except hyphens), and trims leading/trailing hyphens.

### Function Signature

```typescript
function generateSlug(title: string): string;
```

### Parameters

- `title`: The input string (title) to be converted into a slug.

### Return Value

A string representing the generated slug.

### Example

```typescript
import { generateSlug } from '@/lib/utils';

const title = 'My Awesome Course Title!';
const slug = generateSlug(title);
console.log(slug); // Output: "my-awesome-course-title"
```
