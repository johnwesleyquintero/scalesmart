# ScaleSmart CLI Installation Guide

This guide provides detailed instructions for installing the ScaleSmart Command Line Interface (CLI) on various operating systems. The CLI is your primary tool for interacting with the ScaleSmart Platform from your local machine.

## Prerequisites

Before you begin, ensure you have met all the [prerequisites](/docs/prerequisites), especially having Node.js and npm installed.

## Installation Methods

Choose the installation method that best suits your operating system and preferences.

### 1. Global npm Installation (Recommended)

The easiest way to install the ScaleSmart CLI is via npm, which will make the `scalesmart` command available globally in your terminal.

1.  **Open your terminal or command prompt.**

2.  **Run the installation command:**

    ```bash
    npm install -g scalesmart-cli
    ```

    - **Note for Linux/macOS users:** You might need to use `sudo` if you encounter permission errors:
      ```bash
      sudo npm install -g scalesmart-cli
      ```
    - **Note for Windows users:** Run your command prompt or PowerShell as an administrator.

3.  **Verify the installation:**
    After the installation completes, verify that the CLI is correctly installed by checking its version:

    ```bash
    scalesmart --version
    ```

    You should see the installed version number printed to your console. If you receive an error like `'scalesmart' is not recognized`, ensure that your npm global packages directory is included in your system's PATH environment variable.

### 2. Local Project Installation (Advanced)

For specific project setups, you might prefer to install the CLI locally within your project. This is useful if you need a specific version of the CLI for a particular project or want to manage it as a project dependency.

1.  **Navigate to your project directory:**

    ```bash
    cd path/to/your/project
    ```

2.  **Install the CLI locally:**

    ```bash
    npm install scalesmart-cli
    ```

3.  **Run CLI commands:**
    When installed locally, you'll need to run CLI commands using `npx` or by referencing the local `node_modules/.bin` directory:

    ```bash
    npx scalesmart --version
    # or
    ./node_modules/.bin/scalesmart --version
    ```

## Post-Installation Steps

After successfully installing the CLI, proceed with configuring your environment and initializing your project as described in the [Getting Started Guide](/docs/getting-started).

## Updating the CLI

To update your ScaleSmart CLI to the latest version, simply run the global installation command again:

```bash
npm update -g scalesmart-cli
```

This will fetch and install the newest version, overwriting the old one.

If you encounter any issues during installation, please refer to the [Troubleshooting Guide](/docs/troubleshooting).
