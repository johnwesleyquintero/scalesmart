# API Reference

This section provides comprehensive details on how to interact with our RESTful API.

## Authentication

All API requests must be authenticated. Use your API key in the `Authorization` header.

### General API Structure

All API endpoints are prefixed with `/api/`. Requests and responses are typically in JSON format.

### Authentication

All API requests must be authenticated using an API key. Include your API key in the `Authorization` header as a Bearer token:

```
Authorization: Bearer YOUR_API_KEY
```

### Error Handling

API errors are returned with appropriate HTTP status codes and a JSON body containing an `error` message and a `code` for specific error types.

```json
{
  "error": "Unauthorized",
  "code": "AUTH_001"
}
```
