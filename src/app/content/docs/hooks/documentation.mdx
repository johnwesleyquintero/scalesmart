# Hooks Documentation

This directory contains documentation for custom React hooks used within the ScaleSmart application.

## Overview

Custom hooks provide reusable logic and state management for React components. This documentation outlines the purpose and usage of each custom hook.

## Key Areas

- **useMobile:** Hook for detecting mobile device usage.
- **useToast:** Hook for displaying toast notifications.

## Subdirectories

- **use-mobile/:** Documentation for the `useMobile` hook.
- **use-toast/:** Documentation for the `useToast` hook.

Further details on each hook can be found in the respective subdirectory.
