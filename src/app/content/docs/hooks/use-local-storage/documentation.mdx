# useLocalStorage Hook Documentation

## Overview

The `useLocalStorage` hook (`src/hooks/use-local-storage.ts`) provides a way to persist state in local storage. It is designed to be a simple and easy-to-use hook that can be used in any React component.

## Functionality

- **Persist State in Local Storage:** Stores a value in local storage and updates it whenever the component re-renders.
- **Server-Side Rendering Compatibility:** Provides a way to initialize the state with a server-side value to avoid hydration issues.

## Technical Details

- The hook uses the `useState` hook to manage the state of the value.
- The hook uses the `useEffect` hook to initialize the state with the value from local storage.
- The hook uses the `localStorage` API to store and retrieve the value.

## Usage

```typescript
import { useLocalStorage } from '@/hooks/use-local-storage';

const MyComponent = () => {
  const [value, setValue, removeValue, hasAttemptedInitialLoad] = useLocalStorage('my-key', 'initial value', 'server initial value');

  return (
    <div>
      <p>Value: {value}</p>
      <button onClick={() => setValue('new value')}>Set Value</button>
      <button onClick={() => removeValue()}>Remove Value</button>
      {hasAttemptedInitialLoad ? <p>Initial load complete</p> : <p>Loading...</p>}
    </div>
  );
};
```

## Parameters

- `key`: The key to use for storing the value in local storage.
- `initialValue`: The initial value of the state.
- `serverInitial`: The initial value of the state on the server.

## Return Value

The hook returns an array with four elements:

- The current value of the state (or undefined if not yet loaded).
- A function to update the value of the state.
- A function to remove the value from local storage.
- A boolean indicating whether the initial load from local storage has been attempted.
