# Development Workflow

**Code Checking**

```
Resolve: Errors, Problems and Warnings

Execute the `npm run check` command. Analyze the terminal output from `npm run check`, or the provided @problems and @terminal data, with meticulous accuracy. For every error and warning, precisely identify the file, line number, and the complete message. Construct a detailed debugging plan for each, including potential root causes and a prioritized sequence of actions. After each debugging step, and without introducing new issues or altering existing functionality, re-execute `npm run check` and re-evaluate the output with the same level of scrutiny. Iterate through this process of identification, debugging, and verification until `npm run check` yields a clean output, free of errors and warnings. Conclude with a comprehensive report summarizing each resolved issue, the debugging steps taken, and the reasoning behind each action.
```

**Build**

```
Resolve: Errors, Problems and Warnings

Execute the `npm run build` command. If the build fails (exits with a non-zero code or reports errors/warnings), analyze the output, identify the root causes of the failures, and implement necessary code modifications to resolve them. After each modification, re-run the `npm run build` command. Continue this iterative process of diagnosing, fixing, and rebuilding until the `npm run build` command completes successfully with a clean build (no errors or warnings) and exits with a zero code. Document each iteration, including the error/warning encountered, the implemented fix, and the result of the subsequent build.
```
