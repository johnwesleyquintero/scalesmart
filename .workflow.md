# Development Workflow

**Code Checking**

```
1. Execute: npm run check

2. Analyze the terminal output from `npm run check`, or the provided @problems and @terminal data, with meticulous accuracy. For every error and warning, precisely identify the file, line number, and the complete message. Construct a detailed debugging plan for each, including potential root causes and a prioritized sequence of actions. After each debugging step, and without introducing new issues or altering existing functionality, re-execute `npm run check` and re-evaluate the output with the same level of scrutiny. Iterate through this process of identification, debugging, and verification until `npm run check` yields a clean output, free of errors and warnings. Conclude with a comprehensive report summarizing each resolved issue, the debugging steps taken, and the reasoning behind each action.
```

**Git**

```
Task Steps:

1. Execute `npm run check`, and fix identified issues until all checks pass without errors and warnings. Proceed to the next step only after successful completion of this process.

2. @git-changes Execute Git commands to commit and push all staged changes to the remote repository. Generate concise, descriptive, and informative commit messages that accurately reflect the nature and scope of each change. Prioritize messages that clearly explain *why* the changes were made, not just *what* was changed. Use the imperative mood in commit messages. After committing and pushing, verify the successful execution of the operations and report any errors.
```

**Browser**

```
1. Execute: npm run dev

2. Analyze the web page at `http://localhost:3000/` for usability, accessibility, performance, and design. Provide specific, actionable recommendations for improvement, including code snippets or examples where applicable. Prioritize suggestions based on impact and feasibility, and categorize them by area (e.g., UI/UX, SEO, Code Optimization).
```
