# Development Workflow

**Code Checking**

```
1. Execute: npm run check

2. Analyze the terminal output from `npm run check`, or the provided @problems and @terminal data, with meticulous accuracy. For every error and warning, precisely identify the file, line number, and the complete message. Construct a detailed debugging plan for each, including potential root causes and a prioritized sequence of actions. After each debugging step, and without introducing new issues or altering existing functionality, re-execute `npm run check` and re-evaluate the output with the same level of scrutiny. Iterate through this process of identification, debugging, and verification until `npm run check` yields a clean output, free of errors and warnings. Conclude with a comprehensive report summarizing each resolved issue, the debugging steps taken, and the reasoning behind each action.
```
